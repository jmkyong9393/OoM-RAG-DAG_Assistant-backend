# data/logs — 합성 업무 로그 (D-1)

시연·평가용 가공 데이터. 실명·실제 시스템명 없음. `POST /logs/bulk` 로 적재한다(D-2 `scripts/load_logs.py`).

| 파일 | ws | 건수 | 체인 |
|---|---|---|---|
| `sw-dev_v1.json` | 1 SW 개발 | 60 | 배포 이미지 pull 403 · DB 커넥션 풀 고갈 · 토큰 만료 401 · 빌드 캐시 손상 · 컨테이너 OOM · 외부 API 502/배포 롤백 (+ 고아 ref 2) |
| `hr-ga_v1.json` | 2 인사·총무 | 40 | VPN E-403(교육 미이수·인증서) · 계정 잠김 5회 · 메일함 용량 · 출입카드 · 전자결재 ORA-12154 · 재택 장비 반납 (+ 고아 ref 1) |

점검: `python scripts/validate_logs.py` → 규칙 위반(ERROR)·완료 기준 미달(FAIL) 0 이어야 한다.

## 형식

```json
{"workspace_id": 1, "version": "v1", "description": "...", "items": [
  {"ref": "c1-root", "type": "fail", "title": "...", "body": "...",
   "parent_ref": "c1-root"  또는  "parent_refs": ["c1-token", "c1-perm"],
   "source": "synthetic", "source_ref": "syn-sw-001",
   "error_code": "HTTP 403", "keywords": ["..."], "resolution_summary": "...",
   "created_at": "2026-07-03T09:40:00+09:00",
   "expected_queries": ["..."],            // 평가용. 적재 시 제거
   "_refine": true,                         // 정제 비움(워커 검증용). 적재 시 제거
   "_deprecate_reason": "..."}              // 적재 후 PATCH status=deprecated. 적재 시 제거
]}
```

- `ref` 는 파일 안에서만 쓰는 참조. 부모는 **앞에 나온 항목**만 가리킬 수 있다(bulk 규칙). `parent_refs` 가 다중 부모.
- `source_ref` 로 재적재가 멱등(`existing`). 시드(`fe-mock-*`)와 겹치지 않는다.
- `success` 의 `created_at` 은 루트보다 뒤 — bulk 가 루트 `resolved_at` 을 이 값으로 채운다.
- 에러 코드 표기는 의도적으로 섞었다: `HTTP 403`·`HTTP 502`·`E-403`(추출됨) / `TimeoutException`·`OOMKilled`·`ECONNREFUSED`·`ORA-12154`(현재 정규식이 못 잡음) / 없음.

## 완료 기준 대조 (validate_logs.py 출력)

| 기준 | 목표 | v1 |
|---|---|---|
| 건수 | 100 (ws1 60 · ws2 40) | 100 |
| 타입 | fail 50 / success 35 / ref 15 | 50 / 35 / 15 |
| 체인 | ws 당 6+ | 6 · 6 |
| 다중 부모 | 3+ | 4 (`c1-std` `c4-std` `c6-gate` `h2-guide`) |
| 고아 ref | 2~3 | 3 |
| 정제 비움(`_refine`) | 30 | 30 (ws1 18 · ws2 12) |
| 폐기(`_deprecate_reason`) | 3+, success 1+ | 3 (`c1-manual` success · `c4-wrong` fail · `h2-form` ref) |
| `expected_queries` | 60+ | 100 (구어·오타 12) |
| 깊이 | 2~4 | ≤4 |
| 모순 체인 | 1~2 | 1 (`c6-deploy`: 에러율 0.6% 로 기준 1% 미달이지만 수동 롤백) |

## 의도적으로 어렵게 쓴 질의 — 고치지 말 것

평가셋(D-3)이 전부 맞으면 측정 의미가 없으므로 일부 `expected_queries` 는 일부러 변형했다. 리뷰 때 "오타"로 보고 수정하지 않는다.

| 유형 | 노드 | 질의 | 시험하는 것 |
|---|---|---|---|
| 오타 | `c3-root` | 토큰 만료**되서** 로그인 튕겨요 | 돼서→되서 (가장 흔한 맞춤법 오타) |
| 오타 | `c4-root` | 빌드 **캐쉬** 깨졌을때 어떻게 했어 | 외래어 표기 흔들림 → 토큰이 달라져 어휘 검색 실패 |
| 오타 | `h3-root` | 메일함 용량초과로 **매일** 못받아요 | 자판 오타(메일→매일) |
| 오타 | `h2-root` | 비번 틀려서 잠겼는데 어케 **품** | 줄임말+오타 |
| 붙여쓰기 | `c2-root` | **커넥션풀** 꽉찼을때 어케했어 | kiwi 가 한 토큰으로 묶어 `커넥션`·`풀` 과 안 맞음 |
| 붙여쓰기 | `c6-root` | **결제api** 502남 어쩌지 | 한영 붙여쓰기 |
| 소문자 코드 | `c5-root` `h5-root` `h1-root` | **oom** 났는데… / 결재 올리면 **ora** 에러나요 / **vpn** 403 뜸 | 대소문자·축약 코드 |
| 줄임말 | `c1-root` `c4-root` `h1-root` | …못받아옴 403**뜸** / ci 캐시 깨진거 **어케** 고쳤지 / vpn 403 뜸 재택 첫날**임** | 메신저 말투 |
| 동의어 | `h2-saved` | **비번 바꿨는데** 계정이 계속 잠겨요 | 노드는 `비밀번호 변경` — 동의어 사전·벡터 없이는 실패 |
| 복합어 | `c6-cb` | **서킷브레이커** 적용한 사례 | kiwi 분절이 문맥마다 달라짐 → `workspace_terms` 등록 대상(지시서 E-1) |

위 질의 중 어휘 검색(lex 모드)으로 못 맞히는 것이 4개(`커넥션풀`·`캐쉬`·`비번↔비밀번호`·`서킷브레이커`) — D-3 에서 lex / vec / hybrid 모드 차이를 보여주는 역할.
