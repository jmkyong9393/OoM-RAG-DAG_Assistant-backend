# 개인정보 처리방침 (초안)

> 적용 대상: OoM Assist (기업 업무지식 검색·활용 어시스턴트). 회사명·책임자·연락처는 도입 조직이 채운다. 시행일: ____.

**1. 처리하는 개인정보 항목과 목적**

| 항목 | 목적 | 수집 시점 |
|---|---|---|
| 사번, 이름, 직함, 이메일(선택) | 계정 식별·로그인·워크스페이스 권한 관리 | 관리자 초대 시 |
| 비밀번호 | 본인 인증 (일방향 암호화 저장, 원문 미보관) | 최초 로그인 시 본인이 설정 |
| 접속 IP, 접속 일시, 로그인 성공·실패·잠금 기록 | 접근통제·부정 접속 방지·보안 사고 대응 | 로그인·로그아웃 시 자동 |
| 작성한 업무 로그·질의 내용·피드백 | 서비스 제공(검색·답변·대시보드) | 서비스 이용 중 |

고유식별정보(주민등록번호 등)·민감정보는 수집하지 않습니다.

**2. 보유·이용 기간**
계정 정보는 **재직 종료 또는 계정 비활성화 후 즉시 열람 불가 처리**하고, 접속기록은 **1년** 보관 후 삭제합니다(보호조치 기준 §8 준용). 업무 로그·질의 기록은 조직 지식자산으로 서비스 운영 기간 동안 보관하며, 작성자 식별 정보는 퇴직 시 "퇴직자"로 치환합니다.

**3. 제3자 제공·처리 위탁**
개인정보를 제3자에게 제공하지 않습니다. 답변 생성을 위해 외부 LLM 공급자(예: OpenAI)에 **질의문과 규정·업무 로그 본문**을 전송하며, 이용자는 업무 로그와 질의에 개인정보를 적지 않아야 합니다(작성 지침). 공급자 전송 내용에 개인정보가 포함되는 운영 형태라면 처리 위탁으로 보아 위탁 사실을 본 방침에 공개합니다.

**4. 정보주체의 권리**
이용자는 자신의 계정 정보 열람·정정(이름·직함·이메일)·비밀번호 변경을 서비스에서 직접 할 수 있고, 계정 삭제·처리 정지는 조직의 개인정보 보호책임자에게 요청할 수 있습니다.

**5. 안전성 확보 조치**
- 비밀번호 일방향 암호화(BCrypt), 작성규칙(2종 10자 이상 또는 3종 8자 이상, 사번·연속 문자 금지), 180일 변경
- 5회 연속 실패 시 15분 계정 잠금, 관리자 해제
- 미사용 30분 세션 종료, HttpOnly 세션 쿠키, 전송 구간 TLS
- 접속기록 보관, 관리자 권한 서버 검증, 개인정보 표시 제한(이메일 마스킹)
- 워크스페이스 단위 데이터 격리, DB 계정 권한 분리
